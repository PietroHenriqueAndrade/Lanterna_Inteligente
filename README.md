# Lanterna Inteligente

Aplicativo desenvolvido em Flutter como parte da atividade de revisão da SA02.

O projeto simula uma lanterna inteligente, permitindo controlar seu estado, utilizar um modo automático e ajustar a intensidade da iluminação.

## Funcionalidades

* Ligar e desligar a lanterna
* Indicador visual de estado
* Modo automático
* Controle da intensidade da iluminação
* Animações durante as mudanças de estado
* Interface em tema escuro
* Feedback visual dos controles

## Tecnologias utilizadas

* Flutter
* Dart
* Material Design

## Estrutura do projeto

```text
lib/
└── main.dart
```

A maior parte da aplicação está concentrada no `main.dart`, contendo a interface, os estados da lanterna e as funções de interação.

## Como executar

É necessário ter o Flutter instalado e configurado.

Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

Entre na pasta:

```bash
cd NOME_DO_PROJETO
```

Instale as dependências:

```bash
flutter pub get
```

Execute o projeto:

```bash
flutter run
```

## Objetivo

O objetivo do projeto é colocar em prática conceitos estudados em Flutter, principalmente gerenciamento de estado, criação de interfaces, interação com widgets e utilização de animações.
